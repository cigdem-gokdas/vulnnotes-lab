# VulnNotes — Kırık Defter lab uygulaması

KASITLI OLARAK ZAFİYETLİDİR. Yalnızca kendi bilgisayarında, 127.0.0.1 üzerinde çalıştır.
İnternete açma, gerçek veri/parola/anahtar girme.

## Kurulum
    npm install
    npm run seed
    npm start
    # http://127.0.0.1:3000

Node.js 22.13+ gerekir (dahili node:sqlite modülü için).

Görevler, kurulum ve örnek hesaplar için ödev dokümanına ("Kırık Defter") bak.
